My dotfiles for swayfx

Heavily inspired by / taken from https://github.com/b4skyx/dotfiles, all credits go to them

The install script is for arch linux, and installs all the packages including some optional apps (alacritty, firefox, mpd ncmpcpp etc), enables some systemd user jobs, and copys configs. It will backup all your current configs that it replaces

If you want to install it, I recommend answering yes to the "Do you want to confirm each command?" prompt or reviewing the script beforehand
